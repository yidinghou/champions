What Showdown does (checked 2026-11-26 against smogon/pokemon-showdown master). The charge is a twoturnmove volatile that lasts 2 turns. It stores the target slot, and it is dropped if the release is stopped. The release turn is a hard lock: no switch, no Mega Evolution, and no PP spent. Every rule below cites the file it came from.
