Solver Demo: 2v2

Both players pick at the same time, so there is no "best move", only a best mix. For every pair of choices we play the turn under every chance outcome, score each result, and average. That grid is the payoff matrix, and solving it gives each side's best mix. Looking two turns ahead scores each outcome by solving the next turn too. How this fits together

  1. EnumRng turns each random draw (hit, crit, damage roll, proc) into a branch with a probability instead of a random number.
  2. resolve() replays the turn from a cheap copy of the battle once per branch and returns (probability, end state), merging identical states.
  3. Evaluate each end state, then average by probability. One matrix cell is one resolve() call.
  4. Solve the matrix exactly for the mixed strategy neither side can improve on.
  5. Look deeper by replacing each outcome's score with the value of solving the next turn from there. Cost multiplies at every level.
  6. Prune by searching deeper only for each side's most promising choices after one turn. It is a heuristic, so it can be wrong, and the comparison line above shows by how much.
