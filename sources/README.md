# Usage-data sources for Pokémon Champions

What each site publishes, how well we can trust it, and how to pull it. Numbers below come from a
30-Pokémon sample (MunchStats' top 30 by rank, fetched 2026-11-10); full tables are regenerated by
`python scripts/compare_sources.py` into `comparison.md`. Re-run it after a bigger fetch; the conclusions
below are from a small sample.

```sh
champions sources munchstats [--format doubles|singles] [--limit N] [--refresh] [name ...]   # 10 s crawl-delay
champions sources pikalytics [--limit N] [--refresh] [name ...]
champions sources championslab [--refresh]
champions sources opgg [--limit N] [--refresh] [name ...]       # names as in champions.json, singles
```

Snapshots land in `sources/snapshots/*.json` (committed); raw pages are cached in `sources/cache/`
(gitignored) so reruns resume and parsers can be fixed without re-downloading. What the files and fields
contain is defined in [`docs/DATA.md`](../docs/DATA.md); this page is about how far to trust them.

## Summary

| source | what it is | fidelity |
|---|---|---|
| MunchStats | screen-reads of the game's own Battle Data screens | **Best.** Closest to ground truth; but served data was dated 2026-10-06 |
| Pikalytics | Limitless/tournament teams, Reg M-C | Good for tournament play; move % are on an odd scale (see below) |
| OP.GG | ladder pokédex, Singles only (Doubles tab is client-side) | Plausible, singles only; move lists truncated |
| Champions Lab | ladder + tournaments, own "battle engine" | **Do not trust usage numbers** (smooth curve; disagrees with others) |
| Pokémon Zone | ranked-season pages | Not fetched: sits behind a Cloudflare challenge |
| pokebase.app | tournament teams | Not fetched: same |

Pokémon Zone and pokebase.app block non-browser clients. I did not try to get around that. If you want
them, the options are a browser export or asking the owners; both are your call.

## Findings

**The game itself publishes Pokémon usage as a rank, not a percentage** (MunchStats' About page). So a
"usage %" for a Pokémon is always derived by someone: tournament counts (Pikalytics) or the site's own
model (Champions Lab). Only MunchStats' per-Pokémon *rank* is read directly from the game. Move, item,
ability, nature and spread percentages inside a Pokémon's page are published in-game.

**MunchStats** — internal checks pass: abilities sum to 100, natures 98–100, items 91–99, moves 354–398
(of 400; the game shows only the top 10 moves). Every Pokémon in the sample parsed. Caveat: the page says
"Game data last scraped: October 06, 2026" while its FAQ says nightly, so the served data was five weeks
old when fetched. Check `as_of` in the snapshot before relying on it. Teammates are rank-only.

**Pikalytics** — items and abilities sum to exactly 100. Moves sum to a median of 168 (not 400) across
65–69 listed moves per Pokémon, so its move % are a different measure: ordering matches MunchStats
(Garchomp: Protect, Earthquake, Rock Slide, Dragon Claw near the top) but values are 0.35–0.6× MunchStats'
(Incineroar Fake Out 55.6% vs 97.6%). Use it for move *ranking*, not for "how likely is this move on a
set". It lists abilities Garchomp cannot have in normal play (Trace, Simple, Plus), so the long tail is
noisy. Usage is rounded to whole numbers on the page. Rank agreement with MunchStats on the shared 30:
Spearman ρ = 0.82; top-4 move lists share 3.5 of 4. Only the 57 or so Pokémon linked from its pages
plus the names we feed it are reachable; there is no full roster page.

**OP.GG** — spreads obey the 66-point budget; stats match champions.json except one base-stat mismatch
(see `docs/opgg_review.md`). Singles only, so move lists differ by format (Stealth Rock leads Garchomp
there): top-4 overlap with MunchStats Doubles is 1.5 of 4, which is mostly the format difference, not
an error. Move lists are partial (sum 209 median).

**Champions Lab** — the top-20 usage values fall by an almost constant factor per rank (median 0.965,
range 0.000). Real usage counts are noisy, so this looks modelled or smoothed. It also puts Garchomp at
46.3% (Pikalytics: 21%) and Rillaboom, the top Pokémon elsewhere, outside the top 20. Treat its usage
and winrates as unverified. Its 8 winning teams are real-looking tournament entries but a tiny sample,
and the site's robots.txt says `ai-train=no`, so only one page is fetched.

## Answering the original questions

- **Move likelihood:** MunchStats (in-game, Doubles/Singles) first; Pikalytics for tournament play;
  OP.GG for Singles.
- **Team percentages:** none of the fetched sources gives whole-team (6-Pokémon) frequencies. What exists:
  teammate % pairs (Pikalytics), teammate rank (MunchStats), a handful of winning teams (Champions Lab).
  Pikalytics' "Common Team Cores" and MunchStats' "Top Teams" are on the pages but not parsed yet;
  those are the next thing to add.
